# Pages publiques de Hoomie

Les trois pages que l'application **Hoomie** doit exposer publiquement : accueil, règles de
confidentialité et conditions d'utilisation.

Elles sont **générées** depuis les sources du dépôt de l'application
(`supabase/functions/pages-hoomie/`) : c'est là qu'on les corrige, jamais ici. Une correction faite
directement dans ce dépôt serait écrasée au rendu suivant.

Servies par GitHub Pages.
